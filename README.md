# PS2 Turbo 2.0

Landing page estática em HTML, CSS e JavaScript puro.

## Arquivos

- `index.html`: estrutura da página
- `style.css`: visual retrô / responsivo
- `script.js`: WhatsApp, menu mobile e animações
- `assets/`: imagens opcionais

## Rodar localmente

Basta abrir `index.html` no navegador.

Para testar como site local:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## GitHub Pages

1. Crie um repositório novo.
2. Envie estes arquivos para a raiz.
3. Em Settings > Pages, escolha Deploy from a branch.
4. Selecione `main` e `/root`.
5. Salve.
